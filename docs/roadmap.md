# Roadmap

This is a flexible planning outline based only on the current README direction. Timelines, implementation details, and feature priority are still to be decided.

1. **Foundation** — Confirm the desktop application approach and the boundaries between the UI and processing layers.
2. **Footage workflow** — Establish the planned capture/import and timeline experience.
3. **Highlight workflow** — Evaluate the intended local and cloud AI-assisted analysis for funny, hype, and clutch moments.
4. **Editing and export** — Shape the quick-edit and platform-export flow around the selected highlights.
5. **Refinement** — Test the overall workflow against the goal of a fast, clean, low-friction creator experience.
