# Planned features

The following is the current planned scope from the project README. These are not implemented features.

- Local gameplay capture.
- Video import and timeline scrubbing.
- AI-assisted highlight detection.
- Identification of funny, hype, and clutch moments.
- Quick editing tools for trimming, cropping, captions, and zooms.
- Export presets for TikTok, YouTube Shorts, and Reels.
- A creator-focused interface designed to minimize friction.
